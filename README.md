# DC1_VulnHub

**Student:** Rahul Sinha
**Tech Stack:** Cybersecurity

To perform a penetration test on a deliberately vulnerable lab target in a controlled
environment. The project will cover reconnaissance, service and application
enumeration, exploitation of a suitable vulnerability, post-exploitation, and privilege
escalation. The work will follow a basic penetration testing approach and will focus on
understanding how a vulnerability can be identified, exploited, and addressed.
